# Contributing

We welcome contributions to SNID SAGE!

## Feature Requests & Bug Reports

Have an idea or found a problem? Open an issue:

- **[Feature Requests](https://github.com/FiorenSt/SNID-SAGE/issues/new?template=feature_request.md)** - Suggest improvements or new features
- **[Bug Reports](https://github.com/FiorenSt/SNID-SAGE/issues/new?template=bug_report.md)** - Report problems you've encountered
- **[Discussions](https://github.com/FiorenSt/SNID-SAGE/discussions)** - Ask questions or share ideas

## Other Ways to Help

- **Share templates** - Contribute well-characterized supernova spectra
- **Improve documentation** - Fix typos, add examples, clarify instructions
- **Test and report** - Try SNID SAGE with your data and let us know how it goes
- **Cite us** - If you use SNID SAGE in your research, please cite the paper using the instructions in the [citation guide](../reference/citation.md)

## Code Contributions

Want to contribute code? Great!

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

```bash
git clone https://github.com/yourusername/SNID-SAGE.git
cd SNID-SAGE
pip install -e .
```

For questions about development, open a [Discussion](https://github.com/FiorenSt/SNID-SAGE/discussions).
