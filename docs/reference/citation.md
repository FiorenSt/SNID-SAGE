# How to Cite

If you use SNID-SAGE in your research, please cite the SNID-SAGE paper:

- Fiorenzo Stoppa and Stephen J. Smartt, *SNID-SAGE: A Modern Framework for Interactive Supernova Classification and Spectral Analysis* ([arXiv:2603.28741](https://arxiv.org/abs/2603.28741))

For the current arXiv release, the official BibTeX entry is:

```bibtex
@misc{stoppa2026,
  title={SNID-SAGE: A Modern Framework for Interactive Supernova Classification and Spectral Analysis},
  author={Fiorenzo Stoppa and Stephen J. Smartt},
  year={2026},
  eprint={2603.28741},
  archivePrefix={arXiv},
  primaryClass={astro-ph.IM},
  url={https://arxiv.org/abs/2603.28741}
}
```
